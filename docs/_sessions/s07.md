## \[25\] Investigated dunder methods (large group):

* A look at the dunder methods in this class. Which of these do we know about already?  
  1. <mark>'__abstractmethods__',:  set of all the abstract methods that need to be implemented by the subclasses. Objects can only be instantiated if the set is empty</mark>   
  2.  '\_\_call\_\_',: making an instance callable, i think\! (kinda like a function)  
  3.  '\_\_class\_\_',: referring to object’s class  
  4.  '\_\_delattr\_\_', calls the `del` attribute method which usually deletes the attribute?  
  5.  '\_\_dict\_\_: dictionary containing all of the **attributes** (or methods only, i cant remember)',  
  6.  '\_\_dir\_\_',: gets a list of methods and attributes in a class  
  7.  '\_\_doc\_\_',: Holds the docstring usually declared in triple quotes at the start of methods or classes. Serves as built-in documentation  
  8.  '<mark>__eq__: allows us to check equality</mark>',  `==`   
  9.  '\_\_format\_\_': defines how formatting with things like .format() and f strings is handled, `f”{}”`  
  10.  '\_\_ge\_\_: allows us to check if greater than or equal to another instance', \>=  
  11.  '\_\_getattribute\_\_',: call on every attribute access.   
  12.  '\_\_gt\_\_',: allows you to define an ordering for object instances by stating when an object is strictly “greater than” another object of the same type.  \>  
  13.  '\_\_hash\_\_': describes how an object is hashed (sets/dicts),  
  14.  '\_\_init\_\_',: constructor \- automatically executed when a new object is created from a class. Mainly used to set instance variables, makes the class callable  
  15.  '\_\_init\_subclass\_\_',  
  16.  '\_\_le\_\_', returns true if the first input is less than the second, false otherwise. \<=  
  17.  '\_\_lt\_\_',: this stands for “less than” and returns whether one object is less than another \<  
  18.  '\_\_module\_\_': contains the module name where the class is defined,  
  19.  '\_\_ne\_\_',  returns true if the first and second inputs are the same, False otherwise \!=  
  20.  '\_\_new\_\_', controls how a new instance is created before \_\_init\_\_  
  21.  <mark>'__reduce__'z: returns instructions to rebuild an object from a byte string,</mark>  
      * <mark>Used by Python’s pickle module to break down object into bytes</mark>  
      * <mark>The __reduce__ method needs to return a tuple with at least two elements:</mark>  
        * <mark>A blank object class to call</mark>  
        * <mark>A tuple of arguments to pass to the class constructor</mark>  
        * <mark>optional object state to be passed back into the recreated object</mark>  
        * <mark>optional iterator used to append items to the object</mark>  
        * <mark>optional iterator of key-value pairs to add to the object using obj[key] = val</mark>  
        * <mark>optional method with (obj, state) signature that is prioritized over the _setstate_() method if added</mark>  
      * <mark>The function/class returned is used to recreate the object</mark>  
      * <mark>The arguments are then passed into the callable object</mark>  
  22.  <mark>'__reduce_ex__',: It tells python how to save and rebuild an object when you use the pickle module. (pickle is a built in python module that can save and load python objects)</mark>  
      * <mark>Returns a tuple with 2-5 elements that tells python how to reconstruct the object during unpickling</mark>  
      * Attributes:  
        * <mark>Self: The object being pickled(the instance)</mark>  
        * <mark>Protocol: A number that tells what version of pickle format is being used (you can ignore it most of the time).</mark>

        

  23.  <mark>'__repr__': returns the developer/debug friendly string representation used in the REPL</mark>  
      * <mark>The __repr__ method in Python defines how an object is represented when you’re inspecting it. It is meant for developers and should give an unambiguous description of the object that could be used to recreate it. When you call repr(obj), Python shows this value.</mark>  
      * <mark>The __str__ method defines a user friendly, readable version of the object — what you see when you use print(obj).</mark>  
      * Example:  
        <mark>class Point:</mark>

        <mark>def __init__(self, x, y):</mark>  
        <mark>self.x, self.y = x, y</mark>  
        <mark>def __repr__(self):</mark>  
        <mark>return f"Point({self.x}, {self.y})"</mark>  
        <mark>def __str__(self):</mark>  
        <mark>return f"({self.x}, {self.y})"</mark>

        <mark>p = Point(2, 3)</mark>  
      

        <mark>print(p) # (2, 3)   # uses __str__</mark>  
        <mark>print(repr(p)) # Point(2, 3)  #uses __repr__</mark>

    
  24.  '\_\_setattr\_\_', takes the attribute and sts a new user given value to it  
  25.  '\_\_sizeof\_\_',: it tells how many bytes of memory that an object itself uses.  
  26.  '\_\_slots\_\_': restricts instance attributes to save memory,  
  27.  '\_\_str\_\_': returns user friendly string representation to control how an object is displayed when it’s printed  
      	For example, if I had a class Matrix, \_\_str\_\_() might return a readable string representation of the matrix  
  28.  <mark>'__subclasshook__': a special subclass method to customize behavior of issubclass(), meant to identify a virtual inheritance, meaning a similar attribute is found in that subclass in relation to another superclass (can check behavior, not just lineage)</mark>  
  29.  '\_\_weakref\_\_': stores weak references to the object.
