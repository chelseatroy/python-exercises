3. ### (est 3-4 hr) Homework 7 Programming Assignment:

   **First of all, get on a new branch in your repository, and call it homework-7 or something similarly clear.** This will allow you to open a PR to your repo to submit your homework, and then the course staff can comment on your PR to leave feedback. On this branch, make a homework-7 directory. In there:

   

1. Begin a class named `Fraction` that represents a rational number (a number that can be expressed as the quotient of two integers). Python already *has* a fraction class, but please do not import it: for this assignment, you are writing your very own\!   
2. Write a test for the `__init__(self, numerator, denominator)` method to accept integer values for the `numerator` and `denominator` arguments and set instance attributes of the same name. Then implement that in `Fraction` so the test passes\!  
3. Write a test to check that if the `denominator` is 0, initialization raises a `ZeroDivisionError` exception. Then implement that in `Fraction` so the test passes\!  
4. Write a test that, If the `denominator` is negative, the *numerator and denominator’s signs are flipped* to create an equivalent fraction with a positive denominator. Then implement that in `Fraction` so the test passes\!  
5. Write a test to ensure that the Fraction *normalizes—*that is,the fraction 28/20 will get normalized to 7/5. You can use the [math.gcd](https://docs.python.org/3/library/math.html#math.gcd) function to find the greatest common divisor (GCD) of the numerator and denominator and then divide each of them by it to "normalize" the fraction. For example, the fraction 28/20 will get normalized to 7/5 since the GCD of 28 and 20 is 4:  
   	  
    \>\>\> x \= Fraction(28, 20\)  
   \>\>\> x

   Fraction(7, 5\)

6. Test for, and then implement, the basic binary operators (`+`, `-`, `*`, `/`) so that a `Fraction` can combined with either another fraction or an integer. All methods should return a new `Fraction`. Note that you may need to implement "reversed" operators for arithmetic with integers to fully work.  
7. Test for, and then implement, the `__neg__` method returning a new `Fraction` instance with the numerator negated.  
8. Test for, and then implement, the  `__repr__` method returning a string of the form `Fraction(a, b)` where a and b are the numerator and denominator, respectively.  
9. Test for, and then implement, the `__eq__` method returning a boolean indicating that both the numerator and denominator of any two fractions are identical  
10. Test for, and then implement, making the arithmetic operations method work for fractions with floats and integers:

    \_\_repr\_\_(Frac(1, 2\) \+ 1\) \= Fraction(3/2)

    \_\_repr\_\_(1.0 \- Frac(1, 2)) \= Fraction(1/2)

    \_\_repr\_\_(Frac(1, 2\) \* 0.6) \= Fraction(3/10)

    \_\_repr\_\_(0.1 / Frac(1, 2\) \= Fraction(2/10)

    

11. Write tests for, then add, a `.from_float()` and `.from_integer()` class methods to your Fraction class (using `@classmethod`). These should each accept one argument and return a fraction. For example, any of these should return True:

    Fraction.from\_float(1.5) \==  Fraction(3, 2\) 

    Fraction.from\_float(0.125) \== Fraction(1, 8\) 

    Fraction.from\_float(3.0) \== Fraction(3, 1\) 

    Fraction.from\_integer(15) \==  Fraction(15, 1\)

12. Write tests for, then add an `.is_complete()` function as a `@staticmethod` to your Fraction class that accepts any number of fractions and returns `True` if they sum to exactly 1 and `False` if they do not. For this, you'll want to look at the `*args` operator in Python ;). For example, `Fraction.is_complete(Fraction(1, 2), Fraction(1, 2))` should return `True.`For another example, `Fraction.is_complete(Fraction(1, 3), Fraction(2, 3))` should return `True.` Finally for a counterexample, `Fraction.is_complete(Fraction(1, 8), Fraction(6, 8))` should return `False` (this does not add up to 1\)`.`
