### \[30\] Extending the Dataframe to support .append() in pairs 

(20 minutes exercise time. I would like all groups to complete through Part H, and if you finish early, continue): 

[data\_frame\_exercise/phoenixcel/src/dataframe.py](https://github.com/chelseatroy/python-exercises/blob/main/data_frame_exercise/phoenixcel/src/dataframe.py)

5. <mark>Write a test for a function called .append() that lives on DataFrame and allows you to “add dataframes together”</mark> *vertically*. <mark>For example, if you have df with a column called “letters” with the values “a,” “b,” and “c”, and a dataframe called other with a column</mark> *also* <mark>called “letters” with the values “d,” “e”, and “f”, df.append(other) should return a dataframe with a column called “letters” and the values, in order: [a, b, c, d, e, f].</mark>   
   6. Once you have a test, implement this functionality.  
   7. Decide, by writing a test, how you want to handle vertically appending dataframes where one dataframe has some columns that the other dataframe doesn’t have. What’s the behavior there? Throw an error? Return a dataframe that only contains the columns that matched? Return a dataframe that concatenates the columns that matched, and then for the ones that didn’t match, insert a default value across all rows from the dataframe that didn’t have that column? How is that default value set? Whichever thing you choose, write a test and then implement it.   
   8. Have your .append() function now take in a parameter that indicates whether to append vertically or *horizontally*, and write a test for *horizontal* appends. That is, for two dataframes with *different* columns and the *same* number of rows, have it return a dataframe with *all* the columns that differ between the two dataframes.  
   9. Decide, by writing a test, how you want to handle horizontally appending dataframes with different numbers of rows. What’s the behavior? Throw an error? Return a dataframe that only appends up to the *smaller* number of columns? Return a dataframe that appends to the *larger* number of rows, but puts in default values for the columns from the dataframe with the smaller number of rows? If so, how is the default value set? Whichever thing you choose, write a test and then implement it.   
   10. Decide, by writing a test, how you want to handle horizontally appending dataframes that have *shared* column names. Is that an error? If not, whose version of the column are you taking? Why? Write a test and implement.
