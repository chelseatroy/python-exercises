   Write a decorator called @transactional, which accepts a function that returns true or false. 

   This decorator should be able to decorate any function that takes in a table as its only parameter and then makes writes (adding, updating, or deleting columns or data) to that table. 

   

   The decorator starts a transaction. At the end of the function it decorates, it runs the condition function. If that condition function returns true, it commits the transaction. If that condition function returns false, it rolls back the transaction.

   Example of what it looks like to use the decorator and then write code in the function it decorates that cause the changes to *commit*:

   

   ```python
   @transactional(condition=lambda table: table.get_column("product") is not None)
   def add_products(table):
       products = ["duck", "loofah", "bubble_bath"]
       table.add_column("product")
       table.update_column("product", products)
   ```

   

   Gives you:  
   ![Notebook cells applying a transactional decorator to add_products, then showing the product column](../../assets/img/s03/image1.png)

   Example of what it looks like to use the decorator and then write code in the function it decorates that cause the changes to *roll back:*

   

   ```python
   def all_the_prices_are_floats(table):
       for price in table.get_column("price"):
           if isinstance(price, float):
               continue
           else:
               return False
           return True
   @transactional(condition=all_the_prices_are_floats)
   def add_price_incorrectly(table):
       table.update_column("product", ["duck", "loofah", "bubble_bath"])
       #These are not floats
       table.update_column("price", [None, None, None])
       # this should roll back, as the condition is false
   ```
