### \[60\] Extending the Dataframe to support .append() 

Large Group Review of the following functionality from last session’s exercises:

1. Write a function called .append() that lives on DataFrame and allows you to “add dataframes together” *vertically*. For example, if you have df with a column called “letters” with the values “a,” “b,” and “c”, and a dataframe called other with a column *also* called “letters” with the values “d,” “e”, and “f”, df.append(other) should return a dataframe with a column called “letters” and the values, in order: \[a, b, c, d, e, f\].   
2. Additional functionality to discuss and implement:
 - Non-matching columns
 - Horizontal append
 - Appended rows that still belong to the original dataframes
 - The same column holding different types
