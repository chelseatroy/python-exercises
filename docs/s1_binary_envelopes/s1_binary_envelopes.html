A puzzle about counting

The Teller's Envelopes

A bank teller has $1,000 in $1 bills and a pile of envelopes. Before the bank opens, they want to fill envelopes so that any customer can be handed any whole amount from $1 to $1,000 by passing over sealed envelopes, never opening one. How few envelopes can they use?

Each envelope holds a power of the base: $1, $base, $base², and so on, with base − 1 envelopes of each size. Change the base and watch what happens to the envelopes.

Why do some bases need more envelopes?

Work it out yourself first, then open this to check.
  1. Each envelope is a yes-or-no choice: the teller hands it over or keeps it.
  2. With k envelopes, that's 2 × 2 × … × 2 = 2k different handoffs.
  3. The teller must be able to make 1,000 different amounts. One more handoff is always used up by handing over nothing, which makes $0. So they need 2k ≥ 1,001, which makes k at least 10. That's (1000).bit_length(), the number of binary digits in 1000.
  4. Base 2 reaches that minimum because almost every handoff lands on a different amount. In bigger bases, many handoffs land on the same amount (the dark squares above). Every duplicate is a choice the teller paid an envelope for and got nothing new.

Same switches, different meanings

A computer stores numbers in switches that are on or off, just like envelopes that are handed over or kept. A way of storing numbers wastes nothing when every on/off pattern means a different number.

This chip has 4 switches, so it can hold 16 different patterns. Pick a way of reading the switches and watch what the patterns mean.
